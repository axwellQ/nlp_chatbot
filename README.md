# 🤖 NLP Chatbot

Умный чат-бот с обработкой естественного языка на Python.

## ✨ Возможности

- 💬 Интерактивный чат с AI
- 🧠 NLP движок на TF-IDF + Cosine Similarity
- 📊 Статистика и аналитика
- 🎓 Обучение новым интентам через UI
- 🧪 Тестирование распознавания
- 📤 Экспорт/импорт данных
- 📚 REST API

## 🚀 Запуск

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Загрузка NLTK данных (автоматически при первом запуске)

# 3. Запуск
